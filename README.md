# Personal Portfolio Website

## About the Project

This is my personal portfolio website. I created it to show a little about myself, some of the projects and assignments I have worked on, and a way for visitors to contact me.

## Pages

- Home
- About Me
- Projects
- Contact Me

## Features

- Four separate HTML pages
- Personal photo and video
- HTML5 video with controls and a poster image
- Contact form with validation
- Responsive design
- Separate CSS files for different screen sizes
- Media queries
- Linear gradients
- Navigation between all pages

## Responsive Design

I used three separate CSS files to make the website responsive on different screen sizes.

- Desktop: 961px and above
- Tablet: 481px to 960px
- Mobile: 480px and below

I used these sizes so that the layout can adjust depending on whether the website is being viewed on a laptop, tablet, or phone. The project boxes, navigation, images, video, and contact form change in size or layout to fit smaller screens.

## Gradients

I used two types of gradients in the website.

A regular linear gradient is used in the header. It moves from one shade of pink to another from left to right.

An angled linear gradient is used in the footer at 135 degrees. I used a darker shade of pink at the end of the gradient so that the change in colour can be seen more clearly.


## Color Scheme

I used a monochromatic pink color scheme with neutral colors. I used different shades of dusty pink and rose for the header and footer, with white and light gray for the background areas and dark gray for the text. I chose this scheme because it keeps the website simple, consistent, and easy to read.

The color scheme was chosen using the color scheme concepts from Adobe Color.

Main colours used:
- Dusty pink: #D8A7B1
- Rose pink: #C98F9E
- Dark rose: #B76E79
- Light gray: #F4F4F4
- Dark gray: #222222
